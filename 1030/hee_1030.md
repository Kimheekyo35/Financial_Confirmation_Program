# 20261030

## Trouble Shooting
저축은행 데이터(저축은행_050.json) 는 bank_name이 전부 "저축은행" 이라서 어느 저축은행인지 구분이 안 됨. 실제 은행명은 branch_name의 앞부분 (**금화** 영업부)

-> 해결 방법
1. branch_name 앞의 은행명을 떼어 bank_name으로 올림.

----
변경전 : bank_name = 저축은행
        branch_name = 금화영업부

변경 후: bank_name = 금화저축은행
        branch_name = 영업부

추가적으로 
{
  "050_001": "BNK저축은행",
  "050_002": "CK저축은행",
  "050_003": "DB저축은행",
  "050_004": "DH저축은행",
  "050_005": "HB저축은행",
}
다음과 같은 추가적인 index를 생성하여 금융조회서 내 금융기관명에 저축은행이 들어오면 구분할 수 있게 구성.

---

위 방식으로 해결되지 않는 건 `unresolved`에 담음. "상상인플러스"의 경우 띄어쓰기가 적용되지 않아 코드로 구분되지 않아 별도의 **토큰**으로 만들어 상상인플러스저축은행도 구축할 계획.
