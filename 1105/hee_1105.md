1. Codex 설치하면서 Linux 구성요소 이해

Codex를 서버에서 실행하다가 Sandbox 관련 권한 문제가 발생하면서:

- sudo
- Node.js / npm
- Sandbox
- bwrap / Bubblewrap
- user namespace
- AppArmor

```
Codex
  ↓
bwrap
  ↓
Sandbox 생성
  ↓
Linux user namespace 등의 기능 사용
  ↓
AppArmor가 권한 검사
```
문제는 AppArmor가 bwrap의 일부 동작을 차단하고 있었다는 거였고, 그래서 Bubblewrap과 AppArmor 관련 profile을 적용하는 작업을 진행함.

- Sandbox = 격리된 작업실
- bwrap = 작업실을 만드는 도구
- AppArmor = 건물 보안요원
- profile =  출입규칙

-> 권한을 부여하여, codex가 파일을 만들고, 수정할 수 있는 환경 조성

2. PostgreSQL을 Azure 서버에 설치

</sudo apt install postgresql>
</sudo -u postgres psql>

- postgresql = DBMS/서비스 이름
- postgres = 기본 관리 사용자
- psql = PostgreSQL CLI

3. PostgreSQL과 pgAdmin의 차이

- 내가 사용하는 데이터베이스

```
Azure VM
└── PostgreSQL
      └── 실제 데이터 저장
```
**pgAdmin**

**PostgreSQL 을 관리하기 위한 GUI**
```
내 Windows PC
└── pgAdmin
```

따라서, pgAdmin과 Azure DB를 SSH Tunnel로 연결함.
```
내 PC
│
│ pgAdmin
│
│ SSH : 22
▼
Azure VM
│
│ localhost : 5432
▼
PostgreSQL
```

pgAdmin에는 크게 인증이 **두 단계** 필요함.
1. SSH 인증
```
Tunnel Host = Azure Public IP
Port        = 22
Username    = azureuser
SSH Key     = Azure SSH Key
```

2. PostgreSQL 인증
```
Host     = localhost
Port     = 5432
Username = postgres
Password = PostgreSQL 비밀번호
```
